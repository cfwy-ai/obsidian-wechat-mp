# Obsidian 插件 · 公众号排版

在 Obsidian 里写完一篇文章，点一次「复制图文」，粘到微信公众号后台，样子和本地预览一致。

装完插件就能用：不填 AppID、不填 AppSecret、不授权任何第三方服务，也不需要图床。

内置 10 套图文主题，每套都有自己的字体、配色、装饰素材与版式结构。

---

## 它解决什么问题

公众号后台的编辑器不认 Markdown，样式要一段一段手动调。
第三方排版工具通常只给几套模板，字体和装饰改不动，而且往往要把文章内容交给它的服务器。

这个插件把排版放在你自己的 Obsidian 里：文章是你的本地文件，主题是可读可改的 CSS 与素材，复制出来的是一段自包含的富文本。

---

## 功能

- **实时预览** — 右侧显示微信兼容后的排版结果，桌面 677px，手机可在 320–430px 之间调
- **一键复制图文** — 图片转为内嵌数据，粘贴即所见即所得，不依赖外部链接
- **导出长图** — 固定 677px 宽度，长文自动分片再拼成一张 PNG，保存后回读校验
- **10 套主题** — 下拉菜单可搜索切换，每套带配色圆点
- **一级标题图片化** — 用主题自带字体实时光栅化成图片，绕开公众号只认系统字体的限制
- **文章头图** — 每篇文章可单独选择或上传头图，按主题分别记录
- **标题换行** — 在标题里用 `<br>` 控制断行位置

最后一步始终由你人工发布，插件不会自动操作公众号后台。

## 安装

需要 Obsidian 1.8.0 或更高版本，仅支持桌面端（macOS / Windows / Linux）。

```bash
git clone https://github.com/cfwy-ai/obsidian-wechat-mp.git
cd obsidian-wechat-mp
npm install
npm run build
node scripts/install-with-themes.mjs "/path/to/YourVault"
```

把最后一行的路径换成你自己的 vault 目录（那个含有 `.obsidian` 的文件夹）。

装好后重启 Obsidian，在「设置 → 第三方插件」里启用「长风无月 · 公众号排版」。

已有配置不会被覆盖：升级时 `data.json` 原样保留。

## 主题装在哪里

主题包随插件装进插件目录，**不会在左侧文件树里多出任何文件或文档**：

```text
你的 vault/
└── .obsidian/plugins/changfeng-wechat-mp/
    ├── main.js
    ├── manifest.json
    ├── styles.css
    └── themes/              10 套主题：CSS、素材、字体、组件
```

如果你想自己改主题、做新主题，把主题目录放到 vault 里任意位置，在插件设置的「风格目录」填上那个路径即可。
插件优先读插件目录里的主题包；那里没有时才回退读 vault，两种形态可以并存。

## 开发

```bash
npm test               # 自动测试
npm run build          # 生成 dist
npm run check          # 测试 + 主题审计 + 构建
```

主题审计与几个回归工具需要一个真实 vault，通过环境变量指定：

```bash
WECHAT_MP_VAULT="/path/to/YourVault" npm run audit:themes
```

渲染管线是单一真相源：预览、复制图文、导出长图消费同一份微信兼容 HTML。
界面层不另写文章渲染逻辑。

```text
Markdown
  → 正文图片与 wikilink 解析
  → section#nice
  → 主题组件与素材注入
  → HTML 净化
  → 主题 CSS 内联
  → PostCSS 微信兼容过滤
  → 最终 HTML ─┬─ 预览
               ├─ 复制图文
               └─ 导出长图
```
