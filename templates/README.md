# 使用与字体

正文按插件真实模板渲染；文章图片按内容需要选择，不强制每篇使用四种解释图。
字体与文件以 manifest.json 为准，原始字体和随附许可保留，本项目 MIT 许可不改变各字体自身许可。
文心喜乐采用同轮廓的浏览器兼容文件，原字库、原覆盖表和转换报告保留。
配图文字由图像模型绘制，真实字形参考不能保证逐点等同于字体。

通用信息组织见 [信息层级与排版.md](<信息层级与排版.md>)。
本地展示不代替公众号保存重开与手机检查。
