本文档只回答一件事：每个对外版本改变了什么。

---

# 0.10.2

- 恢复星尘手记的方正清刻本悦宋、蜡笔手绘的文心喜乐、解构插画二级标题的京华老宋。
- 导出按源 manifest 保留原定字体，继续验证字库与覆盖表资源。
- 字体映射及说明同步到模板和配图 Skill，原随附许可文件保留。
- 修复文心喜乐中「喔、检、版、远」的 Chromium 空白字形，保持原轮廓、家族和字宽；原字库及转换记录随包保留。

---

# 0.10.1

- 库内主题缺少介绍图时，按稳定主题 ID 补充发行版介绍图，并标注发行版来源及待确认状态。
- 当前主题自己的介绍图始终优先；发行版图片不可读时保留本地预览，不改变模板来源、选中主题或用户配置。
- 图片回退说明统一为「预览图」，避免把封面误称为正文预览。

---

# 0.10.0

- 新安装默认使用 10 套内置模板，无需作者 Vault 或额外上传素材。
- 开发者可显式使用库内主题；旧配置及已选主题在升级后保留。
- 修复隐藏目录素材在复制与导出时无法按普通 TFile 读取的问题。
- 设置页增加模板介绍入口，支持视觉样张（待确认）状态和缺图说明。
- 安装前校验完整资源，升级保留用户配置并在替换失败时回滚。
- 仓库按 `plugin/`、`templates/`、`skills/` 组织。
- 公开模板建立资源清单与文件校验。
