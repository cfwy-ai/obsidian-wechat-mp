# 未发行

- 修复引用块在公众号里多出一条左侧竖线：微信会给原生 `blockquote` 补这条线，内联的 `border` 盖不住。原先只有会把引用转成图片的主题才换掉原生容器，其余主题照样带着 `blockquote` 进微信。现在复制与导出前统一换成普通 `section`，十套一致。
- 修复表格圆角在公众号里变成直角：单元格圆角只在 `border-collapse: separate` 下生效，而这两个属性此前不在微信兼容白名单里，主题根本没办法保住圆角。白名单已补，纪念碑谷的表格同步改为 `separate`。
- 修复深底表头的文字在公众号里发灰看不清：表格文字容器原先只靠继承拿颜色，微信会给最内层节点补自己的 `color` 盖掉它。颜色现在直接写在文字容器上。
- 修复铅笔写意代码块在宽版心下的两处错位。文字内边距原先是固定 25px，而卷轴侧框线按宽度等比在 6.1% 处，版心一宽就压线，改为 8% 等比。块内那幅兰亭插画原先按容器宽度的 85% 缩放、高度随比例长到 163px，而代码块高度由行数决定、版心越宽越矮（677px 下仅 66px），插画被裁到只剩最密的中段压在文字后面；改为 `contain`，插画永远不超出代码块本身，窄版心下的观感不变。卷轴左上角的笔墨纸三图标原先靠固定 25px 左边距与正文对齐，正文改为 8% 后就对不上了，现已改用同一个 8%。
- 尾图可以关掉了：工具栏原来的「更换头图」改名为「头图尾图」，面板底部新增「展示尾图」开关，关闭后这篇文章不再输出主题的正文末尾那一段。设置按主题分开记，写在文章属性的 `wechat_footers` 里；展示尾图是默认值，所以只有关闭时才留痕，重新打开会把这一项删掉。
- 修复长图导出时全角开括号与后一个字重叠：正文里出现「、【」这类闭标点紧接开标点时，Chromium 会把开括号收窄成半角，而长图靠 canvas 绘制、画的仍是全角字形，墨迹落进下一个字。长图页现在关闭这项收窄。
- 公开模板目录改为「01. 纪念碑谷」这样的序号加中文名；主题身份仍是 `theme_id`，已安装的主题不受影响。
- 模板介绍图的可选头图标签上移 6px，画布尺寸不变。
- 手机预览打开时工具栏与正文共用中线，不再向右溢出。
