# 目录

| 位置 | 职责 |
| --- | --- |
| `plugin/` | Obsidian 界面与插件入口 |
| `src/` | 文章渲染与主题契约 |
| `scripts/` | 构建、验证、安装、打包 |
| `test/` | 自动回归测试 |
| `dist/` | 本地构建的完整安装目录，不入 Git |
| `releases/` | 本地生成的 ZIP 和校验和，不入 Git |
