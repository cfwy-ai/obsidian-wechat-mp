# 两个 Skill

- [公众号排版](长风无月-公众号排版/SKILL.md)：保留原文，只调整结构；金句使用引用。
- [公众号配图](长风无月-公众号配图/SKILL.md)：先选模板，再选封面或段落配图，完整图文一次生成。

将对应文件夹交给你的 Agent，安装到它的 Skill 目录。
插件本身不依赖这两个 Skill 即可使用。
在仓库中使用配图 Skill 时，会自动读取旁边的 `templates/`；单独安装时可以显式提供插件内置模板目录。

发布文件的源哈希记录在 `snapshot.json`。
