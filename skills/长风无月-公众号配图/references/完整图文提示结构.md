本文档只回答一件事：怎样将信息层级、布局和模板风格装配成一次完整生图的提示。

先完成 `信息层级与排版.md` 的选择，只填本次需要的字段，不把工作单画进图片。

```text
用途与内容关系：文章封图 / 正文解释图 / 轻量图 / 明确要求的头图；主从 / 顺序 / 对照 / 分组
画幅：横封 2.35:1、方封 1:1；正文配图统一 16:9，只有用户明确要求其他比例时改变并记录原要求
正文内容太密时减装饰、调整层级或拆图，不自行改成 1:1、3:1 或其他比例
来源与阅读目标：读者看完要理解什么

准确文字清单：
L1 主结论：「……」
L2 分组标签：「……」「……」
L3 对应短解释：标签A →「……」；标签B →「……」
数字、单位、条件或否定词：逐项登记，不改强度和含义
不生成清单以外的英文小字、装饰标签、占位字或水印

布局与阅读顺序：
采用何种关系结构与构图，为什么适合这份信息
标题区、信息区与说明区各在何处，行列、对齐线和组间留白如何安排
第一眼看到 L1，然后按什么顺序读 L2/L3
哪些信息同层，哪些标签和解释成组；箭头具体表达什么
简单封图没有解释需求时不强行补 L2/L3，不默认做成三张卡片

模板视觉：
主题 ID 与本次用途；哪些规则只适用于新封图/正文图，哪些属于既有头图/组件
媒材：笔触、纸片、颜料或印痕怎样构成物体，不能仅列颜色和字体
疏密与留白：本主题的连续空白、着色范围和文字区怎样分配；文字也占构图面积
细节上限：保留哪些识别点，省略哪些描边、纹样、环境与重复细节
允许主体：按主题列本图可用的物象与明确禁用的主体，不跨主题复制人物或无人物约束
背景和主要色值
重点色承担什么信息职责
H1 主结论字形参照、H2 分组标签字形参照、辅助说明字形
每张参考图只负责字形 / 色板 / 材质 / 疏密 / 形体中的哪一项，不自动继承其人物与完整场景
主体先符合本主题边界，再说明它对理解的作用；纯文字关系图不强加人物动作

手机阅读与边界：
所有必要文字在目标手机宽度清楚，按词组或短句换行
文字不足以讲清时保留短解释，不用少字口号掩盖信息空洞
文章封图按约定留出四边与底部双角余量，其他用途按实际画幅安排

一次生成含全部准确文字、文字层级、图形和背景的完整图片
不是无字底图，不预留后期叠字，不输出等待拼装的文字层
```

描述具体的信息关系与位置，不只要求「高级」「有设计感」。
同内容换模板时保留文字、层级和语义关系，再装配所选主题的四项风格约束；必要的空间调整不得改变事实。
错字、漏字或层级失败时指出失败处，修改后整图重生成。
