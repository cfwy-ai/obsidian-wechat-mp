# 范围与身份

稳定身份：`dune-echo`，显示名「沙丘版画」。
以下主体与面积约束用于新文章封图、正文配图；既有正文组件、可选头图及其素材保持各自原规范。
新图不出现人物、手、人体局部或人形剪影，不画完整书桌、室内或山水、电影叙事。

---

# 媒材、疏密与细节

浅砂纸 #E8D4B8 上只落极少橙色与墨黑 #251D21 平涂印痕，用少量刻线和缺墨边缘交代形体。
颗粒只附着实际印刷色面，不把纸面铺成沙暴、菲林噪点或电影背景。

保留至少约 60% 没有文字、图形和装饰覆盖的纸面，插画实际着色约占 15%—25%；文字另计入构图，不为留白缩小必要文字。
面积看实际落笔、印痕或纸片覆盖与连续空白，不把背景纸色、主体外接矩形或浅色满铺当作画面留白。

一组主要印痕配少量细线即可，不重复铺满沙脊、风线、星点、机械细节与远景。

---

# 允许主体

采用孤立纸页、短弧、圆日、低沙脊局部或经简化的单件器物，让方向、分组或前后关系服务文字。
物象只点到能读懂关系，不延伸成大场面，不用沙虫、军队或飞行器群替代信息层级。
流程与对照可以有少量相同语言的印痕；保持可比尺度，让大部分纸面安静连续。

---

# 色彩与字形

橙黑用于局部物象与重点，正文解释保持清楚的深色；不把整张图变成橙黑色板。

| 层级 | 字形方向 |
| --- | --- |
| 一级标题 | 寒蝉端黑宋 ChillDuanHeiSong，坚实、有艺术张力。 |
| 二级标题 | 同字体降低字号；必要短引句可用朱雀仿宋。 |
| 辅助说明 | 清楚的宋体或无衬线；短引句可参考朱雀仿宋。 |

实际 H1、H2 文件或系统字形以当前 manifest 为准；真实字形参考与模型绘字分开记录。
避开照片壁纸、三维金属、渐变体积、独立贴纸合集与四角密集徽章；不宣称官方电影字体，不在角落重复主题名。
准确文字、图形与纸面一次完整生成，不先生成无字底图再排字。
