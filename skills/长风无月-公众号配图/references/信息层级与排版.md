本文档只回答一件事：怎样先把要说的信息排清楚，再为它选择模板风格。

---

# 先列准确文字

从源段落提取这张图要回答的问题，再逐条列出实际要出现的文字。
分清用户指定逐字保留的文案、可忠实压缩的解释，以及仅供画面参考的背景。
保留改变判断的步骤、条件、否定词、数字与单位，不因追求少字删掉它们。
未被列入文字清单的英文、装饰标签、水印和占位字不生成。

信息图的核心可以只有文字、连线与有意义的符号，不必添加人物故事或动作。
确有解释价值的图形才保留；装饰不能替代具体内容。

# 用三层组织信息

| 层级 | 职责 | 排版方式 |
| --- | --- | --- |
| L1 主结论 | 让读者先知道这张图在说什么 | 一个明确标题或结论，最大、最先读到 |
| L2 分组标签 | 显示步骤、对象或比较维度 | 同层同强度，位置和顺序一致 |
| L3 短解释 | 补足做法、理由、条件、数字与单位 | 紧靠对应标签，比 L2 安静但手机可读 |

简单封图可以只有 L1；需要解释的方法图不要只剩标题与三个空标签。
L3 可用一两句短说明或必要的条目，不设机械字数上限。
文字总量服从阅读目标与手机尺寸：信息够用、关系明确、能看清才算完成。
不要用省略关键条件、把文字缩成蚂蚁大小或把标题切成碎词的方式塞满画面。

主标题、标签、解释分别使用 H1、H2、辅助字形方向。
先确定内容层级，再利用字号、字重、颜色和间距拉开差异；不要每层都用同样抢眼的艺术字。
中文按完整词组或短句换行，数字与单位、否定词与其对象不随意拆开。

# 关系决定网格与阅读路径

| 内容关系 | 优先结构 | 需要核对 |
| --- | --- | --- |
| 一个结论及支持信息 | 主从布局：主结论配若干紧邻说明 | 次要信息确实支持主结论 |
| 有先后或分支的过程 | 顺序路径、步骤带或必要的分支 | 顺序来自原文，分支条件清楚 |
| 两种做法或状态比较 | 左右、上下或同维度行列对照 | 比较尺度一致，对应项对齐 |
| 多个同类对象或方面 | 分组网格、围绕核心或分类清单 | 分组依据明确，不虚构先后 |
| 归纳要点或核对完成条件 | 总结清单、检查表或按维度分组 | 检查项来自原文，不能新增评判标准 |
| 情绪、章节或话题过渡 | 轻量图：一组标题与少量意象 | 不承担被省略的重要说明 |

先划出标题区、信息区与必要解释区，再决定行列数、各区宽度与留白。
同层元素沿共同对齐线排列；相关标签与解释靠近，无关组之间拉开距离。
明确第一眼、第二眼和最后阅读的位置；箭头只表达真实顺序、方向或因果。
三步可以是一条连续路径，三组也可以主从分布，不自动把任何内容塞成三张卡片。

# 九种构图只作选择库

用户的海报参考提供构图方向，不是九套需要全部套用的成品模板。

| 构图 | 可借用的组织方式 | 边界 |
| --- | --- | --- |
| 上下 | 上方主结论，下方解释或证据 | 不是把每段都居中堆叠 |
| 居中 | 围绕单一核心建立第一阅读点 | 长说明仍需清楚的行列 |
| 左右 | 图文分工或同维度对照 | 两侧权重服从关系 |
| 对角 | 用方向形成视线移动 | 标签保持可读，不为斜线打乱顺序 |
| 对称 | 表达同等地位或成对关系 | 不把主次强行做成等重 |
| 四角 | 核心与四个相关方面 | 仅在确有四项时使用 |
| 散点 | 展示没有顺序的同类对象 | 用间距和分组保持归属 |
| 包围 | 多个支持项围绕一个核心 | 连线不能凭空增加因果 |
| S 形 | 沿连续路径安排真实顺序 | 路径和文字不能缠绕、跳读 |

不照搬参考海报中的伪英文小字、碎标题、任意装饰编号和无意义标签。
构图服务于本次内容；不同风格可以共用清楚的结构，同一风格也应按关系换布局。

---

# 最后装配风格并验收

信息安排完成后才加入所选模板的色板、H1/H2/辅助字形与材质。
真实字体样张约束字形方向；模型画出的文字仍需逐字检查，不能当作精确调用字库。
图文一次完整生成，图形和材质留在信息分区以内，不用装饰遮盖排版问题。

依次检查：准确文字无遗漏 → L1/L2/L3 层级可辨 → 阅读路径正确 → 分组和对齐清楚 → 手机缩图可读。
如果 L3 不清楚，先增大信息区、减少重复装饰、调整网格或拆分图片；只有不影响理解的内容才可删减。

# 参考依据

[IBM Carbon 字体规范](https://carbondesignsystem.com/elements/typography/overview/)支持按标题、正文等角色建立有区别且一致的排版层级。
[NN/g 邻近原则](https://www.nngroup.com/articles/gestalt-proximity/)说明靠近的元素更容易被读作一组，因此标签与解释应靠近、组间应留出距离。
[GOV.UK 颜色规范](https://design-system.service.gov.uk/styles/colour/)支持按用途区分颜色角色，并检查文字与背景的对比。
本项目同时用文字、位置或形状表达层级，不只依赖换色。
以上用于信息组织，不直接采用来源的品牌字体、色值或网页字号。
九种构图、16:9 默认画幅和手机缩图检查是本项目按用途作出的选择，不是这些来源规定的公众号标准。
